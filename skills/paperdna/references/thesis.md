# 学位论文补充

除了遵守论文写作的通用原则（`references/word_style.md` 第 1 节），学位论文还要注意以下几点：

- 常见结构：绪论 → 背景 / 相关工作 → 方法 → 实验 / 结果 → 讨论 → 结论。
- 章首用一段话概述本章内容，以及它与前后章的关系；章末可以小结，并引出下一章。
- 术语和符号全文统一，不要各章分别定义同一个概念。
- 概念在首次出现的地方解释，不要让读者跨几十页回头找定义。
- 删掉与论证无关的历史回顾，避免没有新信息的重复陈述。
- 避免指代不明（"该方法""this"可能指向多个对象）和从句层层嵌套的长句。
- 语气正式、平稳、有条理。

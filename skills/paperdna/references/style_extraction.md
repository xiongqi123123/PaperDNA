# 从样本提取文风

输入：用户过去写的 3–5 篇（或 3–5 段）高质量文本，最好是同一类型，例如都是英文会议论文。

## 分析维度

1. **句法**：平均句长，长短句怎么搭配；常用句式，如强调句、倒装，以及特定连接词（Therefore / Notably / Conversely）；主动语态与被动语态的比例；人称（we、被动语态，还是"本文"）。
2. **词汇与语气**：用词是平实还是书面化；有哪些标志性的动词和形容词；语气是否客观中立、克制，自信到什么程度。
3. **微习惯**：标题格式；引用和举例的方式；标点偏好（破折号、分号、冒号）；段落长度。

## 输出

- 按 `profile/style_profile.md` 现有的结构（语气 / 句式 / 个人偏好 / 个人禁忌）给出更新内容。每条尽量附上样本中的一个原句作为例子。
- 先把与现有画像不同的地方展示给用户，确认后再写入。与现有条目冲突时，问用户保留哪一条。
- 通用的去 AI 味规则不写进画像，它们已经在 `references/word_style.md` 第 4 节里。
